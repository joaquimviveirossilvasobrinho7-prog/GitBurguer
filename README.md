# 🍔 Burger House

Site de hambúrgueria artesanal com carrinho de pedidos, carrosséis de produtos e animações.

## 📁 Estrutura
| Arquivo | O que faz |
|---|---|
| `index.html` | Estrutura da página |
| `style.css`  | Todos os estilos |
| `script.js`  | Produtos, carrinho e interações |

## 🌐 Bibliotecas usadas (via CDN)
- **Swiper.js** — carrosséis de hambúrgueres e bebidas
- **AOS** — animações ao rolar a página
- **SweetAlert2** — alertas e confirmações

## 🚀 Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex: `burger-house`)
2. Faça upload destes 3 arquivos na **raiz** do repositório
3. Vá em **Settings → Pages**
4. Em **Source**, selecione a branch `main` e a pasta `/(root)`
5. Salve — o site fica em `https://SEU-USUARIO.github.io/burger-house/`

> ⚠️ Os arquivos precisam ficar soltos na raiz do repositório, sem pasta no meio.
> ⚠️ O site precisa de internet para carregar as bibliotecas e as imagens (Unsplash).
